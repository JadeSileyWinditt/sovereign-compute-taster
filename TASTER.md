# Sovereign Compute — Taster

**Jobs keep running when nodes disappear and packets drop.**

## Run
```bash
bash setup_and_run.sh
```

## What this shows
- k-of-n placement
- kill + resume-after-delay
- packet drops on a real UDP loopback
- state that survives restart

## What this does not include
Full dual-ledger isolation, causal checks, production transport, and the complete framework.
